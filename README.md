# Billy Prasasti Portfolio (Next.js)
```
npm install
npm run dev     # http://localhost:3000
```
Deploy: push to GitHub and import into Vercel (zero config).
Edit content in `app/page.js` and `app/Experience.js`. CV file: `public/Billy_Prasasti_CV.pdf`.

Photo: save your photo as `public/photo.png` (transparent-background PNG looks best) and set `PHOTO = "/photo.png"` in `app/page.js`.
